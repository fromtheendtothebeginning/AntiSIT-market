# SIT大物实验提醒

AntiSIT 的 Cordis 拓展：把学校「基础信息平台」下 **报告系统** 里大学物理实验的报告列表读出来，
只显示**未提交**的那些，按提交截止时间排列，并给出实验开始时间、截止时间与倒计时；到点前用系统通知提醒。

## 它做什么

* 登录实验平台（学号 + 密码），只读地拉一次学生报告列表；
* 主列表只列「未提交」：按截止时间从近到远，逾期单列一段并用红色描边；
* 每行显示：报告名、课程、开始时间、截止时间、剩余 / 逾期时长；
* 「超时提交」单独一页，回看哪些报告交晚了；
* 提醒默认提前 1 天 / 3 小时 / 30 分钟（可勾选增减），走 App 的系统通知，App 没开也能弹；
* 后台刷新可选（前台服务 + 常驻通知，每 30 分钟同步一次）。

## 隐私

* 学号存在普通存储里（只用来显示与下次登录），**密码只写进 `ctx.secrets`**（Android Keystore /
  iOS Keychain，按拓展隔离）；
* 密码在源码、日志、界面里都不出现明文：输入框是 `type=password`，插件不打日志；
* 不上传任何数据，除了发给学校实验系统本身的登录与列表请求。

## 网络

实验系统是校内**明文 http**（`http://210.35.98.35:8000` 基础信息平台、
`http://210.35.98.35:8003` 报告系统），没有证书，所以走 App 1.44.0 起的
`ctx.net.campus` 通道（`campus_net` 权限）：

* 只允许 http，目标可以是内网地址，但仍拒绝本机 / 回环 / 链路本地 / CGNAT；
* 服务器模式下 App 会自动把校园隧道代理（`http://host:port`）注入这条通道，
  设备不一定要在校园网里；直连模式则要求设备自己在校内网。

## 与「学习通截止提醒」的关系

两者互不依赖：

* **学习通截止提醒**（`sit.deadline-reminder`）管学习通上的作业 / 考试；
* **SIT大物实验提醒**（本拓展）管学校实验平台里的大物实验报告。
