# 截止提醒 · sit.deadline-reminder

按截止时间陈列**未完成**的作业与考试，并在到点前推送本地通知。

## 功能

* **一屏陈列**：未完成条目按截止时间升序排列；逾期的一组标红置顶，未逾期的一组紧随其后。
* **剩余时间**：每条显示「剩 3 天 4 小时」「已逾期 2 小时」，每 30 秒刷新。
* **弹窗提醒**：
  * 打开拓展时，如果有逾期或 24 小时内到期的条目，弹一次汇总窗；
  * 保存条目时按勾选的提前量预约系统通知（提前 1 周 / 1 天 / 3 小时 / 30 分钟，可多选），App 没开也会到点弹出。
* **粘贴导入**：把学习通 / 雨课堂里的作业、考试列表整段复制过来，本地解析成条目，默认提前 1 天与 3 小时提醒。
* **已完成**：点左侧圆圈标记完成，主列表只剩未完成项；「已完成」页可以恢复或删除。

## 边界

* 本拓展不联网，也不读取任何账号；「粘贴导入」只解析你主动粘进文本框的文字。
* App 不包含任何学校专用适配。以后如果要做自动同步，由拓展自己用通用的
  `ctx.secrets`（加密存 Cookie）与 `ctx.net.request`（原生 HTTPS 代理）去对接，
  不需要 App 认识学习通。

## 导入格式

每行一条，日期写成 `2026-11-20 23:59`、`2026/11/20 23:59` 或 `11月20日 23:59` 都行：

```
高等数学 第三章作业 2026-11-20 23:59
线性代数｜期末考试｜12月1日 09:00
大学英语 作文二 2026/11/18 18:00
```

* 没写时间按 `23:59` 算；
* 没写年份时，早于当前日期 45 天以上的按明年算；
* 含「考试 / 期末 / 期中 / 补考 / 考核」的归为考试，含「作业 / 实验 / 报告 / 论文 / 测验 / 习题」的归为作业，其余归为其他；
* 用 `｜` 或 ` - ` 分隔时，前面一段当课程名，后面一段当标题；制表符分列的表格也支持（日期单独一列时，左列课程、右列标题）。

## 数据与隐私

条目只存在拓展自己的 `ctx.storage` 里，不联网、不读取任何账号信息。卸载拓展会一并清掉。
通知走 App 的本地通知渠道（`notification` 权限），首次预约时系统会请求通知权限。
